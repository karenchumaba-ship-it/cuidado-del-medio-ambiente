# cuidado-del-medio-ambiente
proyecto escolar para promover el cuidado del medio ambiente y las practicas responsables
## Descripción
Este proyecto escolar busca informar sobre la importancia de cuidar el medio ambiente y promover hábitos que ayuden a proteger nuestro planeta.
## Objetivo
Crear conciencia sobre la contaminación y enseñar acciones sencillas para cuidar la naturaleza.

- Ahorrar agua y electricidad en casa.
- Evitar el uso innecesario de plásticos.
- Plantar y cuidar árboles y plantas.
- Mantener limpios los espacios públicos.
